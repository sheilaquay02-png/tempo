# Local Tempo Assistant Restore + Mobile Decoration Update

## Restored local Tempo Assistant

The original local Tempo Assistant helper has been restored from the original app source. It is not connected to OpenAI and does not use any API route.

Restored behavior includes:
- Bottom-right floating Tempo assistant button.
- Full local chat-style assistant panel.
- Local context engine for today’s events, tasks, habits, free time, journal patterns, and check-ins.
- Local “rhythm memory” preferences.
- Local assistant action suggestions and confirmation before making changes.
- Local add event / add task flows.
- Local assistant undo history.
- Settings panel for Assistant Rhythm Memory.

No OpenAI/API assistant route was added.

## Mobile decoration editing disabled

Decoration editing is now desktop-only.

On mobile:
- Saved stickers/tape decorations can still display on journal memories.
- The Decorate button is hidden.
- The after-save “Decorate now” prompt is disabled.
- The decoration bottom sheet/tool card is hidden.
- Direct decoration editing cannot be started from mobile UI.

Desktop decoration editing remains available.
