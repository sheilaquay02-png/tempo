# Phase 7 Desktop Layout Hotfix

## Problem

On wide desktop screens, Rituals and Habits cards were capped too narrowly, leaving a large empty space on the right side of the app.

## Fix

- Phase cards now stretch to the full available content width on lifestyle pages.
- Ritual and habit grids now use responsive auto-fit columns.
- Template library cards now fill the page width with more columns on larger screens.
- Existing mobile one-column behavior is preserved.

## Affected pages

- Rituals
- Habits
- Template Library sections
- Today lifestyle cards that use phase-wide-card styling
