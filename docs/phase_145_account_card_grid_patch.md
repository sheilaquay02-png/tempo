# Phase 145 Account Card Grid Patch

## Purpose

Make Budget Account bank/account cards consistent in size and row count.

## Changes

- Account cards now use equal widths and heights.
- Desktop account overview uses a maximum of 5 cards per row.
- Mobile account overview uses 3 cards per row.
- Long account names, subtitles, and balances truncate safely instead of stretching cards.

## Check

1. Open Budget → Account.
2. Confirm account cards are uniform in width and height.
3. Confirm desktop rows show up to 5 cards.
4. Confirm mobile rows show 3 cards.
5. Tap account cards and confirm account detail still opens.
