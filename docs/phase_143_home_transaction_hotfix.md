# Phase 143 Home Transaction Hotfix

Budget Home now supports transaction recording directly from the Home overview.

## Changes

- Expense total row opens the transaction recorder as an expense.
- Income / goals row opens the transaction recorder as income.
- Expense bucket tiles open the recorder with that bucket preselected.
- Income/protected goal tiles open the recorder with that bucket preselected.
- The Transactions page recorder remains available and unchanged.

## Manual checks

- Budget → Home → tap Expense, record an expense.
- Budget → Home → tap an expense bucket, confirm the bucket is preselected.
- Budget → Home → tap Income / goals, record income.
- Budget → Transactions still supports add/edit/delete.
- Account balances and bucket spending update after saving from Home.
