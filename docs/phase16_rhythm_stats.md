# Phase 16 — Rhythm Stats

## Objective
Replace the old narrow daily stats popup with a softer Rhythm Stats dashboard focused on consistency instead of judgement.

## What changed
- Expanded the Rhythm Stats modal into a full consistency overview.
- Added 7-day ritual consistency.
- Added 7-day habit consistency.
- Added best habit streak.
- Added 30-day task completion rate.
- Added 30-day journal entry count.
- Added mood and energy trend summaries from daily check-ins.
- Added Tomorrow Reset and Weekly Reset activity summaries.
- Added most consistent day of week based on tasks, habits, rituals, journal, and check-ins.
- Added completion rate by task category.
- Removed rank/score/badge emphasis from the stats modal copy.

## Tone rule
The stats should feel encouraging and observational:

> Here’s how your rhythm is building.

Avoid failure language. The purpose is to help the user understand their rhythm, not make them feel behind.

- JSX syntax checked with TypeScript parser.
- Core module syntax checked.
- Styles module syntax checked.
