# Phase 143 Home popup recorder hotfix

- The Budget Home transaction recorder now opens as a modal/bottom-sheet popup instead of rendering inline on the Home page.
- Tapping Expense, Income/goals, or a Budget Home category tile opens the popup with the transaction type and bucket preselected.
- The Transactions page now uses a popup recorder launched by Expense / Income / Transfer buttons instead of always showing the form above the calendar.
- The popup is inspired by the reference video: category title header, large amount entry, spent/left strip, quick chips, tool strip, and calculator-style keypad.
- No data model or persistence shape changed.
