# Phase 126+ UX polish

This phase is intentionally visual/copy polish only. No core app mechanics were removed or redesigned.

## Updated

- Tightened Settings panel spacing and hover/focus states.
- Improved Google Calendar settings readability and long calendar-id truncation.
- Polished notification settings copy and card spacing.
- Added stronger keyboard focus-visible rings across important buttons, inputs, and cards.
- Improved mobile Settings sizing around the bottom navigation area.
- Added small mobile journal modal spacing refinements without re-enabling mobile decoration editing.
- Added reduced-motion handling for users who prefer less animation.
- Preserved local Tempo Assistant/chatbot exactly as a protected feature.

## Not changed

- No OpenAI/API assistant route was added.
- No local Tempo Assistant logic was removed.
- No Google sync mechanics were changed.
- No task, habit, journal, reminder, or sync data mechanics were changed.
- Mobile decoration editing remains disabled; existing decorations still display on mobile.
