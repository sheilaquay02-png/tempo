# Journal Story Decorator Update

This update changes journal decorations to behave like a story-style editor instead of a form-based scrapbook/editor panel.

## Changes

- Desktop decorating now uses a two-card popup layout:
  - left card: the saved journal entry final view
  - right card: decorate tools
- Mobile decorating uses a focused story-style layout with the saved memory view and a compact bottom tool card.
- Decoration editing now happens on the saved journal entry view only.
- Removed X/Y/width/height/rotate slider controls.
- Decorations are moved directly by dragging on the memory card.
- Selected stickers/tape use a corner handle to resize and rotate directly.
- Double-tap/double-click a sticker or tape to open a small contextual menu above it.
- Contextual menu supports flip horizontal, flip vertical, front, back, copy, and delete.
- Sticker picker is now a single horizontal row; scroll sideways to see more stickers.
- Journal view card corners and clipping behavior were adjusted for cleaner rounded-corner display.
